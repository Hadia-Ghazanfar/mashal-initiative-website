# Mash'al Initiative Website

Public website for **Mash'al Initiative** (mash'al | مشعل), a student-led NGO at FAST NUCES, Lahore.

> "Small acts. Meaningful change. Building a kinder tomorrow."

## About

Mash'al Initiative runs community drives in Lahore, including:

- **Rizq-e-Khair** — flour for families (Rs. 31,000 raised, 210 kg flour, 42 families)
- **Gift a Tree, Share a Shade / Shajr-e-Umeed** — 60+ saplings planted (Jaman, Mango, Amrood)
- **Free Bird Seed Packets** — sunflower seeds, pearl millet (bajra), black chickpeas (kala chana)
- **Spark Hope, Feed a Child** — Rs. 270 per meal box
- **Pink Talk** — health awareness with Dr. Khadija Agha
- **SOS Children's Villages Lahore** visit
